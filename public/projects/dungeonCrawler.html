Godot Dungeon Crawler

During my semester in Norway, I attended a game development course where we had to create a video game from scratch in a team. We chose to build a dungeon crawler game using the Godot engine. I only worked with unity before, so it was a great opportunity to learn a new game engine and expand my skill set. We had a lot of fun designing the game mechanics, creating the art assets, and programming the gameplay. It was a challenging but rewarding experience that taught me a lot about teamwork and game development!

The game uses a 2.5D perspective, with 3D environment, 2D sprites, and a fixed camera angle. I designed most of the assets and programmed the generation of the dungeons. I also implemented the player's inventory system and the combat mechanics.
