PHP Weather Station

In my last college semester, I did a project to have a website showing the precipitation of the day or week with different charts and options. I worked with Arduino to collect the data, MQTT to transfer them and PHP and MySQL to get the data from the MQTT broker. Finally I could display them with the help of the Chart.js library.

PHP
MQTT
Arduino
MySQL
HTML/JavaScript

This is the setup I worked with for testing. As you can see, the ultrasound sensor looking down will see how much water is in the bottle. On the screen we can see the data collection with the temperature and the distance. The data are then sent to the MQTT broker and the MySQL database.

This project was another one where I had to come up with the starting idea and make some initial documentation for my client (my teacher). I had real meeting to show the client the progress and the product. It was a nice experience where I was set in a real company workflow.
