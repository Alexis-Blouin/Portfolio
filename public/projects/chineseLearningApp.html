React Chinese Learning App

I built a React app to help me learn Chinese. It’s a simple flashcard-style app where I can add new words, see their translations, and test myself. It’s been a great way to practice both my coding skills and my language learning!

React
Node.JS
MySQL
API
Mui

My goal with this project was to create a support tool to help me follow my Chinese learning journey. To use it effectively, I add the new words I learn in my classes, sort them by chapters and category, and come back later with the flashcard style activity to test myself. It’s been a great way to practice both my coding skills and my language learning!
