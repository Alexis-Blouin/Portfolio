Java CNC Machine Software

During a software development class I had to develop a Java application to create a file interpretable by CNC machine. We were in a team of 5 where I was the leader. We started by making the design diagrams (model, use cases, classes, logical architecture, etc.) and user interface mockups. We then developed the application with the MVC design pattern in mind. I programmed most on the cut systems and the export to the G-code format for the CNC program.
