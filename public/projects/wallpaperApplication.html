Python Wallpaper Application

I built a Python application that puts the time on my desktop wallpaper. I usually hide the taskbar, so I wanted a way to always see the time without having to open an app or check my phone. It’s a simple script that updates the wallpaper every minute with the current time displayed on it. It’s been a fun little project that combines my love for coding and customization!

Python
Tkinter
PowerShell

The application allows me to select an image and a font. I then can place within it the texts (hours, minutes and the split(am/pm)) and choose the color of each of them. I aslo implemented a color palette that choose 5 dominant colors from the image and a color pickier if I want a precise color.
